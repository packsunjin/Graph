## 다룰 사회문제

**로봇·인공지능 자동화로 일자리가 줄어드는 문제 (기술적 실업)와 그로 인한 불평등**

### 책의 핵심 주장 (직접 읽은 쪽수를 옆에 적을 것)

- 이번 기술은 과거와 다르다: 예전 기계는 사람의 힘을 대신했지만, 정보기술은 사람의 판단·사고까지 대신한다. (p. __)
- 단순 반복 일만 사라지는 게 아니다: 기사 작성, 법률 문서 검토, 의료 진단처럼 고학력 사무직도 위협받는다. (p. __)
- 생산성은 오르는데 임금은 제자리 → 이익이 기술·자본을 가진 소수에게 몰려 불평등이 커진다. (p. __)
- 일자리가 줄면 소비할 사람도 줄어 경제 전체가 흔들린다. (p. __)
- 해결 방안으로 **기본소득(보장 소득)** 을 제안한다. (p. __)
