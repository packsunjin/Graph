# 라즈베리파이 블루투스 음악 플레이어

라즈베리파이 4와 블루투스 이어폰, 보조배터리로 만드는 휴대용 MP3 플레이어입니다.
전원을 켜면 노래가 자동으로 나오고, 버튼 5개로 조작합니다.

## 할 수 있는 것
- 전원을 켜면 이어폰에 자동으로 연결하고 노래 재생 시작
- 버튼으로 재생/일시정지, 다음 곡, 이전 곡, 볼륨 조절
- 이어폰 연결이 끊기면 자동으로 일시정지, 다시 연결되면 이어서 재생
- 마지막으로 듣던 곡과 볼륨을 기억
- 재생 버튼을 3초 누르면 안전하게 전원 종료 (SD카드 손상 방지)
- 셔플 켜기/끄기

## 준비물
| 부품 | 비고 |
|---|---|
| 라즈베리파이 4 | |
| microSD 카드 16GB 이상 | 노래를 많이 넣을 거면 32GB 이상 |
| 보조배터리 | **5V 3A(15W) 이상**, USB-C 케이블 |
| 블루투스 이어폰 | |
| 누름 버튼 5개 + 암-암 점퍼선 10개 | 택트 스위치. 없어도 테스트는 가능 |
| (권장) 방열판 케이스 | 주머니나 가방에 넣으면 열이 나기 때문 |

## 버튼 연결

각 버튼의 한쪽 다리는 GPIO 핀에, 다른 쪽 다리는 GND(접지) 핀에 연결합니다. 저항은 필요 없습니다.

| 버튼 | GPIO | 핀 번호 | 짧게 누르기 | 길게 누르기 |
|---|---|---|---|---|
| 재생 | GPIO17 | 11번 | 재생 / 일시정지 | **3초: 전원 끄기** |
| 다음 | GPIO27 | 13번 | 다음 곡 | 2초: 셔플 켜기/끄기 |
| 이전 | GPIO22 | 15번 | 이전 곡 (3초 넘게 들었으면 처음부터) | |
| 볼륨 + | GPIO23 | 16번 | 볼륨 올리기 | 누르고 있으면 계속 올라감 |
| 볼륨 - | GPIO24 | 18번 | 볼륨 내리기 | 누르고 있으면 계속 내려감 |

GND 핀은 **9, 14, 20, 25번** 중 아무 곳이나 쓰면 됩니다.

```
   라즈베리파이 핀 (USB 단자가 아래쪽일 때 왼쪽 열 = 홀수, 오른쪽 열 = 짝수)

        3.3V  1 ● ● 2  5V
              3 ● ● 4  5V
              5 ● ● 6  GND
              7 ● ● 8
         GND  9 ● ● 10
 [재생] GPIO17 11 ● ● 12
 [다음] GPIO27 13 ● ● 14 GND
 [이전] GPIO22 15 ● ● 16 GPIO23 [볼륨+]
        3.3V 17 ● ● 18 GPIO24 [볼륨-]
             19 ● ● 20 GND
```
핀 번호가 다르면 `config.ini`의 `[buttons]`에서 바꿀 수 있습니다.

## 설치 방법

### 1. SD카드에 운영체제 설치
1. 컴퓨터에 [Raspberry Pi Imager](https://www.raspberrypi.com/software/)를 설치합니다.
2. 장치는 **Raspberry Pi 4**, 운영체제는 **Raspberry Pi OS Lite (64-bit)**를 고릅니다.
   화면이 필요 없어서 Lite가 더 가볍고 전기도 덜 씁니다.
3. 설정 편집에서 **사용자 이름과 비밀번호**, **와이파이**를 입력하고, 서비스 탭에서 **SSH 사용**을 켭니다.
4. SD카드에 쓰고 파이에 꽂은 뒤 전원을 연결합니다.

### 2. 컴퓨터에서 파이에 접속
```bash
ssh 사용자이름@raspberrypi.local
```

### 3. 프로그램 받아서 설치
```bash
sudo apt-get install -y git
git clone -b claude/raspberry-pi-music-player-magfwe https://github.com/packsunjin/Graph.git
cd Graph/pi-music-player
./setup.sh
```

### 4. 노래 넣기
파이의 `~/Music` 폴더에 노래 파일(mp3, flac, m4a, ogg, wav 등)을 넣습니다. 하위 폴더도 찾습니다.
컴퓨터에서 이렇게 복사할 수 있습니다:
```bash
scp -r 내노래폴더/* 사용자이름@raspberrypi.local:~/Music/
```
노래를 새로 넣은 뒤에는 재부팅하거나 `systemctl --user restart music-player`를 실행하세요.

### 5. 이어폰 페어링
```bash
./pair.sh
```
이어폰을 페어링 모드로 만들고 Enter를 누르면, 찾은 기기 목록이 나옵니다. 번호를 고르면 연결하고 주소를 저장합니다.
한 번만 하면 다음부터는 자동으로 연결됩니다.

### 6. (선택) 절전 설정
```bash
./power-save.sh              # LED 끄기, 최고 속도 낮추기
./power-save.sh --wifi-off   # 와이파이까지 끄기 (배터리가 더 오래 가지만 SSH 접속이 안 됨)
./power-save.sh --undo       # 되돌리기
```
와이파이는 노래를 다 넣고 설정이 끝난 다음에 끄는 걸 추천합니다.

### 7. 재부팅
```bash
sudo reboot
```
켜진 뒤 20~30초 정도 지나면 이어폰에서 노래가 나옵니다.

## 사용법
- **켜기**: 보조배터리에 케이블을 꽂으면 켜집니다. 이어폰은 켜 두세요.
- **끄기**: 재생 버튼을 3초 누르고, **초록 LED가 깜빡이다 완전히 꺼지면** 보조배터리를 뺍니다.
  그냥 뽑으면 SD카드가 망가질 수 있습니다.
- 버튼 없이 테스트하려면 SSH 접속 상태에서:
  ```bash
  systemctl --user stop music-player
  python3 player.py     # p=재생/일시정지 n=다음 b=이전 +/-=볼륨 s=셔플 q=종료 (입력 후 Enter)
  ```

## 보조배터리 팁
- 10000mAh 보조배터리로 약 6~8시간 들을 수 있습니다 (절전 설정과 와이파이 끄기를 하면 더 오래 갑니다).
- 전압 부족 확인: `vcgencmd get_throttled` 결과가 `throttled=0x0`이 아니면 배터리 출력이 약한 것입니다.
  갑자기 꺼지거나 소리가 끊기면 더 센 보조배터리나 짧고 굵은 케이블로 바꿔 보세요.

## 문제가 생겼을 때
| 증상 | 확인할 것 |
|---|---|
| 아무 소리도 안 남 | `journalctl --user -u music-player -f` 로 기록을 봅니다 |
| "음악 파일이 없습니다" | `~/Music`에 노래가 있는지 확인 |
| 이어폰이 연결되지 않음 | 이어폰이 휴대폰 등 다른 기기에 이미 연결되어 있지 않은지 확인. 안 되면 `./pair.sh` 다시 실행 |
| 이어폰은 연결됐는데 소리가 안 남 | `wpctl status`로 Sinks에 이어폰이 있고 `*` 표시가 붙어 있는지 확인. 재부팅도 해 보세요 |
| 버튼이 안 먹힘 | 배선 확인(한쪽은 GPIO, 한쪽은 GND), `config.ini` 핀 번호 확인 |
| 전원 끄기 버튼이 안 됨 | `./setup.sh`를 다시 실행 |

## 파일 설명
| 파일 | 하는 일 |
|---|---|
| `player.py` | 음악 플레이어 본체 |
| `config.ini` | 설정 (음악 폴더, 이어폰 주소, 버튼 핀, 볼륨) |
| `setup.sh` | 필요한 프로그램 설치, 자동 실행 설정 |
| `pair.sh` | 블루투스 이어폰 페어링 |
| `power-save.sh` | 보조배터리용 절전 설정 |
| `music-player.service` | 부팅할 때 자동 실행하는 설정 파일 |
