# 생기부 자기평가서 작성 도우미 (Claude Code용)

학교에서 받은 **자기평가서 양식**(창의적 체험활동 / 교과 세특)을 학생과 함께 채우고,
**검증관 3명(규정 · 입학사정관 · 서술)**이 서로 협의 없이 따로 판정해 **3명 모두 통과해야 최종본**이 되는 워크플로입니다.

결과물은 **학생 본인이 쓰는 1인칭 자기평가서**입니다. 생활기록부에 그대로 들어갈 문장이 아니라, 선생님이 관찰 기록과 함께 참고하는 자료입니다(아래 [주의사항](#주의사항) 참고).

---

## 사용법

1. 이 저장소를 Claude Code로 엽니다.
2. 다음 중 하나를 입력합니다.
   - `/saenggibu`
   - "생기부 자기평가서 같이 쓰자"
3. Claude가 질문을 보여 주면 보기 2개 중 하나를 고르거나, **Other(직접 입력)**에 내 경험을 그대로 적습니다.
4. 초안이 나오면 검증관 3명이 판정합니다. 반려·보완이 나오면 Claude가 다시 묻고, 답에 맞춰 고쳐 씁니다.
5. 3명 모두 통과하면 최종 자기평가서를 받습니다. 이것을 학교 양식에 **내 손으로 옮기면서 내 말투로 다듬어** 제출합니다.

> 학교 양식이 이 저장소의 양식과 다르면 양식 파일(PDF·한글·텍스트)을 Claude에게 보여 주세요. 섹션 이름·과목명·문장 수 제한을 학교 양식에 맞춰 바꿔 씁니다.

## 흐름

```
① 학기·학교 양식 확인
   - 몇 학년 몇 학기인지, 어떤 양식(창체 / 교과 세특)인지, 과목·영역 목록, 칸별 문장 수 제한
   - 학교 양식이 없으면 templates/ 의 기본 양식 사용
        ↓
② 섹션별 질문 (AskUserQuestion)
   - 한 섹션당 질문 4개 이하
   - 질문마다 보기 2개 + Other(직접 입력)
   - 학생이 말하지 않은 사실은 절대 지어내지 않음 → 빈칸은 다시 질문
        ↓
③ 1인칭 자기평가서 초안 작성 (guides/작성자가이드.md 기준)
        ↓
④ 검증관 3명 독립 판정 (병렬, 서로 협의 없음)
   - A 규정 검증관     : 기재요령 금지사항·글자 수·관찰 가능성
   - B 입학사정관 검증관: 학업·진로·공동체역량, 수업 연결, 과정 중심, 수준 적합성
   - C 서술 검증관     : 문장 구체성, 탐구 서사, 칭찬어·중복·압축
        ↓
⑤ 3명 모두 '통과'? ── 예 ──→ 최종본
        │
        아니오(반려 / 조건부 통과)
        ↓
⑥ 사유를 학생에게 설명하고 되묻기 → 재작성 → ④로 (최대 3회)
   - 3회 후에도 남은 쟁점은 학생에게 그대로 보고하고 선택을 맡김
```

## 핵심 규정 요약 (2026학년도 기재요령 기준)

출처: 17개 시도교육청 「2026학년도 학교생활기록부 기재요령(고등학교)」 [참고자료 8] 최대 글자 수 표(원문 p.208).

| 항목 | 최대 글자 수(한글 기준) | Byte | 비고 |
|---|---|---|---|
| 자율·자치활동 특기사항 | 500자 | 1,500B | 학년 단위 (3학년은 '자율활동') |
| 동아리활동 특기사항 | 500자 | 1,500B | 학년 단위 |
| 진로활동 특기사항 | 500자 | 1,500B | 학년 단위 (2025년 700자 → 2026년 500자) |
| 과목별 세부능력 및 특기사항 | 과목별 500자 | 1,500B | 일반·진로·융합선택 과목 (예: 대수) |
| 공통과목 세특 | **1·2 합산 500자** | 1,500B | 공통국어·공통수학·공통영어·통합사회·통합과학·한국사·과학탐구실험 (2022 개정, 2026학년도 1~2학년) |
| 행동특성 및 종합의견 | 300자 | 900B | 2025년 500자 → 2026년 300자 |

- 교육정보시스템(NEIS)은 Byte로 셉니다. **한글 1자 = 3Byte**, 영문·숫자 1자 = 1Byte, 엔터 = 1Byte.
- 최대 글자 수는 **학년 단위**입니다(과목별 세특은 제외). 그래서 창체는 1학기와 2학기가 같은 500자를 나눠 쓰고, 공통과목은 1과 2를 합쳐 500자입니다.
- 어떤 항목에도 쓸 수 없는 것: 교내·외 대회 및 수상, 공인어학시험, 논문 투고·학회 발표, 도서 출간, 특허, 해외 활동, 부모 직업·지위 암시, 장학금, 특정 대학·기관·상호·강사명, 학교를 알 수 있는 정보, 자격증, 모의고사 성적 등.
- 세특 추가 금지: K-MOOC·MOOC·KOCW, 방과후학교 활동, 연구보고서(소논문) 관련 사항(일부 과제탐구 과목 예외).
- 수행평가는 수업 중 실시가 원칙이며, 과제형(집에서 해 오는) 수행평가는 금지됩니다. → 자기평가서도 **수업 중 과정**이 드러나야 합니다.

자세한 판정 기준은 `guides/` 폴더의 검증관 기준서에 있습니다.

## 주의사항

기재요령은 서술형 항목에 대해 다음 행위를 금지합니다(원문 '작성 시 유의사항').

- 단순 사실을 과장하거나 사실과 다르게 기재하는 것
- **서술형 항목에 기재될 내용을 학생에게 작성하여 제출하도록 하는 것**
- **AI를 활용하여 생성한 자료를 서술형 항목에 그대로 입력하는 것**

그래서 이 도구는 다음을 지킵니다.

- 결과물은 **교사 참고용 학생 자기평가서(1인칭, 사실 기반)**입니다. 생기부 문장(교사 문체)을 대신 써 주는 도구가 아닙니다.
- 학생이 실제로 한 일·읽은 책·얻은 결과만 씁니다. 모르는 부분은 지어내지 않고 다시 묻습니다.
- 자기평가서는 학교가 허용한 학생 작성 자료(동료평가서·자기평가서·수업산출물·소감문·독후감) 중 하나입니다. 다만 **AI가 만든 문장을 그대로 내지 말고**, 내용을 확인한 뒤 내 말로 다시 써서 내세요.
- 학교에서 AI 사용을 제한하거나 신고하게 한다면 **학교 안내가 우선**입니다. 제출 마감·분량·손글씨 여부도 담임·교과 선생님께 확인하세요.
