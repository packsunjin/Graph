# 📸 학습지 100점 시스템 — 사용법

## 너가 할 일은 딱 3가지

1. **학습지를 찍어서 올린다** (한 장이든 여러 장이든 OK)
   - 밝은 곳에서, 종이 전체가 보이게, 글씨가 흔들리지 않게
   - 같이 알려주면 더 좋음: `과목 / 시험 날짜 / 하루에 공부할 수 있는 시간`
2. **만들어진 플랜을 위에서부터 순서대로 따라한다**
   - 체크박스 하나씩 체크. 생각하지 말고 적힌 대로.
3. **틀린 문제를 알려준다** — "변형문제 2번 틀림" 처럼 한 줄이면 충분
   → 오답노트에 기록되고, 그 부분 연습이 플랜에 자동으로 추가됨

## 플랜 구성 (매번 같은 형식)

| 섹션 | 내용 |
|---|---|
| 0. 한눈에 보기 | 시험까지 며칠, 총 몇 문제, 단원/개념 목록, 위험 문제 |
| 1. 핵심 개념 카드 | 꼭 외울 공식·정의만 짧게 |
| 2. 문제별 풀이 | 따라 쓰기만 하면 되는 단계별 풀이 + 함정 |
| 3. 일자별 따라하기 | 25분 블록 단위 체크리스트 |
| 4. 변형 문제 | 숫자·조건을 바꾼 연습 문제 |
| 5. 100점 체크리스트 | 시험 직전 최종 점검 |
| 정답지 | 맨 아래 (먼저 보지 말기!) |

## 모든 개념은 이 5단계로 공부한다

```
① 개념 카드 읽기 → ② 풀이 따라 쓰기 → ③ 풀이 가리고 다시 풀기 → ④ 변형 문제 → ⑤ 채점 & 오답노트
```

③에서 막히면 ②로 돌아가기. ④를 다 맞히면 그 개념은 통과.

## 폴더

- `worksheets/` — 올린 학습지 사진
- `plans/` — 만들어진 플랜 (`날짜_과목_단원.md`)
- `오답노트.md` — 틀린 문제 기록 (같은 유형 3번 연속 맞히면 완료)
- `templates/plan-template.md` — 플랜 양식
