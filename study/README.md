# 📸 학습지 100점 시스템 — 사용법

학습지(선생님이 준 개념 정리 프린트, 빈칸 채우기 프린트 등)를 찍어 올리면,
그 내용을 전부 외우고 이해해서 시험 100점을 맞는 따라하기 플랜을 만들어 준다.

## 너가 할 일은 딱 3가지

1. **학습지를 찍어서 올린다** (여러 장 OK)
   - 밝은 곳에서, 종이 전체가 보이게, 흔들리지 않게
   - 빈칸은 **비워둔 상태**로 찍는 게 좋음 (나중에 가리고 채우기 연습용으로 씀)
   - 같이 알려주면 더 좋음: `과목 / 시험 날짜 / 하루 공부 시간 / 시험 형식(객관식·서술형)`
2. **만들어진 플랜을 위에서부터 순서대로 따라한다** — 체크박스 하나씩
3. **틀린 걸 알려준다** — "예상문제 4번 틀림" 한 줄이면 충분
   → 오답노트에 기록되고, 그 부분 연습이 플랜에 추가됨

## 플랜 구성 (매번 같은 형식)

| 섹션 | 내용 |
|---|---|
| 0. 한눈에 보기 | 시험까지 며칠, 학습지 범위, 출제 포인트 개수 |
| 1. 완성 학습지 | 빈칸 정답을 채운 학습지 전체 (정답은 **굵게**) |
| 2. 출제 포인트 | 시험에 나올 곳 + 중요도 ★★★ |
| 3. 암기 카드 | 질문 → 답, 하나씩 |
| 4. 일자별 따라하기 | 25분 블록 단위 체크리스트 |
| 5. 예상 문제 | 빈칸·객관식·O/X·서술형 |
| 6. 100점 체크리스트 | 시험 직전 최종 점검 |
| 정답지 | 맨 아래 (먼저 보지 말기!) |

## 학습지의 모든 부분은 이 5단계로 공부한다

```
① 완성본 읽기 → ② 빈 학습지에 가리고 채우기 → ③ 암기 카드 → ④ 예상 문제 → ⑤ 채점 & 오답노트
```

②에서 막히면 ①로 돌아가기. ④를 다 맞히면 그 부분은 통과.

## 폴더

- `worksheets/` — 올린 학습지 사진
- `plans/` — 만들어진 플랜 (`날짜_과목_단원.md`)
- `오답노트.md` — 틀린 것 기록 (3번 연속 맞히면 완료)
- `templates/plan-template.md` — 플랜 양식
