# 수어42

카메라 앞에서 수어를 직접 따라 해 보며, 게임처럼 단계별로 배우는 수어 학습 웹앱이에요.
단어는 수어 42개(국립국어원 한국수어사전 표준 수어). HTML·CSS·JS만 쓰고 서버 없이 동작해요.

## 실행 방법
`index.html`을 더블클릭하면 데이터(CSV)를 못 불러와요. 아래처럼 여세요.
- 터미널: `sueo42` 폴더에서 `python3 -m http.server` → 브라우저에서 http://localhost:8000
- 카메라('직접 해보기')는 `localhost` 또는 `https` 주소에서만 켜져요.

## 배포 (Render)
- 저장소 맨 위 `render.yaml`(Render 정적 사이트, 공개 폴더 `sueo42/`, 빌드 명령 없음)을 그대로 사용해요.
  `render.yaml`의 branch는 바꾸지 마세요.
- AI-Hub 원본 데이터(영상·라벨·키포인트)는 올리지 않아요. 학습된 모델(`model/`)만 올려도 돼요(출처 표기).

## 디자인
- taste-skill(design-taste-frontend, MIT, https://github.com/Leonxlnx/taste-skill)의 앱 화면 스타일 'editorial-greeting'을 따랐어요.
  - 흰 바탕 + 한 단계 어두운 둥근 패널(그림자·그라데이션·이모지 없음), 청록(#1b6e66) 한 색은 '해 본 단어' 같은 데이터에만
  - 홈 맨 위 제목은 오늘 해 볼 단어("오늘은 '괜찮다' 차례예요"), 그 아래 숫자 줄과 **나의 42칸**(단계별 6칸, 해 본 칸은 청록)
  - 휴대폰은 아래 탭 바, 넓은 화면(900px 이상)은 왼쪽 메뉴
- 글꼴은 Pretendard 하나 (스킬이 고른 Instrument Sans에는 한글이 없어서 바꿈). 색·크기는 `css/style.css` 맨 위 `:root`
- 확인 도구: 스킬의 `lint.mjs --app`, `inspect.mjs --app` (0 FAIL, 0 WARN)

## 화면
| 하단 탭 | 하는 일 |
|---|---|
| 검색(홈) | 오늘 해 볼 단어, 숫자 줄(레벨·연속 학습·해 본 단어·최고 점수), 나의 42칸(검색창·단계 버튼으로 거르기) → 단어 상세(영상, 사전 표제어, 수형 설명, 사전 링크) |

| 직접 해보기 | 카메라 앞에서 따라 하기 (핵심 기능, AI) |

## 데이터 (`data/words.csv`)
- 열: `번호,단어,사전 표제어,수형 설명,영상,분류,항목 페이지,AI-Hub 문장 수,단계`
  - 단어 = 화면에 보일 대표 단어, 사전 표제어 = 예: `괜찮다,무방하다`(쉼표가 있으면 칸을 `"…"`로 감싸기)
  - 영상 = 사전 mp4 주소(없으면 빈칸 → "영상 준비 중"), 항목 페이지 = 사전 링크, 단계 = 1~7
- 시트 '누리사전 영상' 탭(한국수어사전 B~F열, AI-Hub 문장 수 G열)에서 만든 42개. 구글 시트를 CSV로 게시했다면 `config.js`의 `SHEET_CSV_URL`에 붙여 넣기
- 영상 칸이 빈 단어는 "영상 준비 중"으로 보이고 뜻 맞히기 문제로는 안 나와요(보기로는 나와요). 지금은 42개 모두 영상이 있어요.
- 영상·설명 출처: 국립국어원 한국수어사전(저작자표시-비영리-변경금지) — 영상을 자르거나 편집하지 않아요.
- 열 이름을 바꾸면 `config.js`의 `COLUMNS`도 똑같이 바꾸기

## 게임 규칙 (모두 이 기기 localStorage에 저장)
- **점수·정답·랭킹은 ① 뜻 맞히기에만.** 정답은 사전 근거라 정답 옆에 사전 출처를 보여줘요. 맞히면 +10점(`QUIZ_POINT`).
  이름별 랭킹은 친구끼리 한 기기에서 돌려 쓰는 용도예요.
  - 영상이 있는 단어만 문제로 내요. 그 단계에 영상이 하나도 없으면 수형 설명으로 문제를 내요.
- **단계·레벨·연속 학습·배지는 참여 기준.** 뜻 맞히기를 풀거나(맞든 틀리든) 직접 해보기를 시도하면 '해 본 단어'.
  - 앞 단계 6개를 다 해 보면 다음 단계가 열려요. 레벨 = 해 본 단어 6개마다 +1
  - 배지 목록은 `js/progress.js`의 `BADGES`

## 직접 해보기 원칙 (통합 멘토링 강의)
- AI는 판정하지 않아요. 점수·확률·맞고 틀림을 보여주지 않고, **비슷해 보이는 순위 + 사전 영상·내 동작 나란히 + 선택지**
  ([맞아요] [다른 동작이었어요] [다시 해보기])만 보여줘요. 해 본 기록만 레벨·배지에 반영돼요.
- 지금 순위는 `js/model.js`의 `guessSimilar(frames)`가 임시로(무작위) 정해요. 화면에 "🧪 시험용 — 아직 학습 전"이 나와요.
- 모델을 넣는 방법: TensorFlow.js 모델을 `sueo42/model/model.json`(+ 가중치 파일)에, 출력 순서대로 단어 이름을 적은
  `sueo42/model/labels.json`(예: `["괜찮다","좋다",…]`)을 넣고 `config.js`에
  `MODEL_URL: "model/model.json"`, `MODEL_LABELS_URL: "model/labels.json"` 적기.
  입력 모양은 `[1, 30, 84]` (장면 30개 × 두 손 21점 x·y, 손목 기준·손 크기로 정규화) — `framesToFeatures()`와 똑같이 학습하기
- 카메라 영상은 기기 안에서만 처리하고 어디에도 보내지 않아요. API 키 같은 비밀 정보는 코드에 넣지 않아요.
- 손 인식: MediaPipe Tasks Vision `@mediapipe/tasks-vision@0.10.14` (jsDelivr CDN), 모델 `hand_landmarker.task` (float16/1)
